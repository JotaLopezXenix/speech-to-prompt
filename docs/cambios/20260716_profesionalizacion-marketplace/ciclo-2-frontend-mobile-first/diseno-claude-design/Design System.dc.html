Dirección "B · Papel" — guía de tokens

Editorial y humano: papel cálido, acento verde pino, serif con contención. Todo componente lee tokens, nunca colores directos. Base de la traducción a React + Vite + TypeScript + Tailwind + shadcn/ui.

Para Claude Code — handoff

Lee estos ficheros en el proyecto y reconstruye en shadcn. No copies "mis" primitivos: compón los de shadcn y aplícales estos tokens. Las pantallas (Captura, Revision, Destilado, Resultado) son la referencia de composición y estados; esta página, la de valores.
